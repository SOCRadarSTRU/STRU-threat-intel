Key Points
- Kynx is a new AI-assisted Windows-targeting stealer written in C++ with development history tracing back to at least January 2026.
- Forum activity suggests a Turkish developer is promoting Kynx’s progress and subscriptions.
- The threat actor shifted from code development to an active operational status around June 2026, spinning up their panel and resulting in the first wave of samples appearing on VirusTotal.
- Upon execution, Kynx performs a scored environment check targeting virtual machine indicators with the cumulative score reaching above or equal to 3 terminating the process.
- Kynx features targeted modules designed to extract data across multiple verticals such as browsers by downloading components like ChromeElevator or DumpBrowserSecrets, 65 crypto wallet browser extensions, 19 desktop wallet applications, 16 gaming platforms, 9 VPN providers, 8 AI coding tools, 3 email clients, FileZilla FTP and Discord.
- Exfiltration occurs directly to the web panel via structured HTTP POST requests with data being segmented and transmitted in distinct categories.
- The C2 panel is secured against unauthorized access and replay attacks, requiring an X-Kynx-Token header that is valid for only 5 minutes. Transmitting an invalid or expired token triggers an automated, permanent IP ban on the server side.
